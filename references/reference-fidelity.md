# 高贴近程度的参考迁移

用户明确要求参考发挥实质作用。默认目标是看得出沿用哪张海报的完整设计语言。颜色、纹理和装饰相同，不能单独证明达到要求。

## 生成前的对应关系

看实际海报，记录六项，再说明用户内容分别如何占据这些角色。只有其中适用于该参考的具体特征才成为约束，不能把REF-021的低饱和或两行排字推广到全库。

| 维度 | 需要明确的具体关系 |
| --- | --- |
| 构图 | 主体重心、画面占比、裁切方式、图文位置、留白方向与面积 |
| 氛围与明暗 | 主体和背景谁亮、反差分布、影调、印刷/摄影质感、克制或强烈的程度 |
| 排字 | 标题落点、行数与行长、横向/纵向组织、字重字距、主次字号和对齐 |
| 色彩 | 主辅色角色、饱和度与亮度、各色面积，不能只有色相接近 |
| 视觉冲突与意境 | 写实与抽象、粗与细、实与虚怎样形成联系；图形为何存在、与主体在哪接触 |
| 整体美感 | 图像、字与图形是否共同组织成一个整体，是否滑向未经指定的通用广告模板 |

主体身份和用户文案的意思必须保留，默认使用忠实的英文译文；已确定的英文保持原样。为了贴近参考可做影调、去饱和、裁切、纸感等处理，不要求维持内容照片原始光线和饱和度；用户要求保留原色时以用户要求为准。参考中的人物、品牌、原文仍不得混入成品。

## 画幅适配

参考横版、目标竖版时，不可能维持所有绝对坐标。保持视觉重心、图文顺序、方向性、相对占比和留白作用，再调整间距或行长。不要把横向文字基座自动变成四行巨字。直接在默认3:4的唯一成品画布上完成构图，不再延展成9:16；每次编辑和导出都复核，避免尺寸适配改变已正确的设计关系。

## 实图验收

把参考与实际成品同时打开，按六项逐一用画面证据判断。文字与尺寸合格后，还须完成审美验收。对明显偏离的关键项先修正，不能因为颜色和装饰相似就宣称完成，也不虚构相似度百分比。

若相似度与内容可读性存在冲突，先通过行长、字号、裁切或留白微调解决。确实无法兼顾时说明具体约束，不默默改成另一种风格。

## REF-021的实际纠偏

这张参考的特征是：低饱和灰黑摄影主体偏左；右侧暗部中，细黄线贴着手指转折向右延伸；底部是蓝紫辅字和黄色主标题的横向基座；影调和纸感克制粗粝。

面条封面的失败版本用了居中明亮的整碗面、强白字与高亮黄字、四行纵向堆叠和没有明确连接作用的曲线。虽然出现相近颜色和线条，其构图、氛围、排字、色彩比例和图形逻辑均偏离参考，不能作为高贴近迁移的合格案例。

修正应让用户面条的灰调摄影局部承担左侧主体角色，用面条转折承接细线，恢复底部横向排字和蓝紫/黄的主辅关系。实际是否达到仍须并排看成品，不以提示词已经写到为凭。

本用户在纠偏过程中进一步指定封面全英文。此例最终文案为“Noodles need chopsticks.”和“AI needs brains.”；英文有助于沿用参考的横向字形节奏，但文字语言本身不能替代上述审美验收。
