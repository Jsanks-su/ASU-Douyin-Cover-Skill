# 审美贴近与元素完整性的实图验收

验收对象是实际生成图；任务卡只是预期，不能因为提示词已经写到就判定成品通过。同时打开选定参考、元素映射表/文字清单和成品，完成两轮不同的检查。

## 1. 整体视觉关系

| 维度 | 比较内容 |
| --- | --- |
| 构图 | 主体重心与面积、裁切、图文顺序、负空间方向、疏密节奏 |
| 氛围 | 主体/背景明暗分配、饱和度、反差、摄影与印刷质感，克制或强烈的程度 |
| 排字 | 字形性格、横纵组织、主次字号、行长、字距、共同基线/倾角与对齐 |
| 色彩 | 主辅色角色及面积、亮度与饱和度，不只比较有没有同一种颜色 |
| 冲突与意境 | 粗细、虚实、写实与抽象的对照；图形为何存在、与主体在哪接触 |
| 完整美感 | 主体、文字、线条是否共同组织成整体，是否仍能识别选定参考的设计逻辑 |

横版参考转3:4时保持视觉重心、顺序、方向和相对占比，调整行长与间距。不要求复制所有绝对坐标，也不允许因此自动换成常见的居中主图加四行巨字。

## 2. 元素与文字的逐项核对

对照[元素映射表](content-mapping.md)，为每个ID核对：

- **存在**：主图、副标题、细字、编号、条带文字和框线等是否真的出现；参考有字的色带是否被错误画成空白。
- **内容**：字串、数字、大小写/断行要求是否准确；表格逐格核对，检查缺行、乱码、错列或边线压字。
- **几何与层级**：位置、相邻关系、大小、字重、字距、倾角与对齐是否保持该元素的作用。补上标签但比例关系失真也不合格。
- **依据**：原文、翻译、概括、事实或编辑标识是否仍与任务卡一致；不接受临时新增数字、日期、品牌或卖点。

重要元素不能以“文字太小”“主标题够了”“更简洁”为由静默省略。确需合并/简化，记录其原因和被保留的功能；若大部分辅助层级都消失，应回到选图或构图，而非直接宣称完成。

对于没有摄影槽位的参考，额外检查用户主体是否在任务卡确定的位置可辨认，且融合后核心排字与留白关系仍成立。既不能完全丢掉图片，也不能为放图将整张纯文字参考改成常见照片模板。

## 退回修正的情形

缺失重要角色、空白条带/表格、错字或无依据数据、主体身份改变、主构图或整体影调明显漂移，均退回对应修改。颜色接近和大字可读不能覆盖这些失败。

精细信息可在完整尺寸辨认，主标题和主体应在手机小图尺度清晰；不能为增大所有小字而破坏参考的层级。内部检查左下遮挡及边缘留白，不额外交付检查图。

最终通过只说明本次已按这些证据检查，不虚构相似度百分比，不保证后续每次生成完全相同。Skill结构校验、任务卡演练和实图质量验证分别记录，不能相互替代。
