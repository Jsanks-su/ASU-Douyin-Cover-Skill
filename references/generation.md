# 图生图任务卡

使用当前环境的实际图像工具执行。工具若有配套图像技能，遵守其输入和输出要求。工具不可用时说明缺少的能力，不私自寻找付费服务或伪造成品。

## 生成前

先查看用户图片和选定参考的完整图。缩略联系表用于选图，生成时传入选定参考文件本身。

在内部明确用户图片中必须保留的主体、文案逐字原文、选定参考编号与文件、本次借用的构图与排字，以及为中文文案和用户主体需要做的适配。

读取 [上传与展示构图规则](platform-framing.md)。提示词同时说明上传画布、主页可见裁切、标题安全区与左下播放量避让；平台界面示意图不属于创意素材。若首版不能守住安全区，先把完整内容排成3:4核心，再以相同背景向上下延展为9:16，不得为填满长图把标题重新拉到底部。

将两张图通过工具支持的方式同时传入，并标明顺序与职责。必要时先把已选参考展示到图像上下文，确认用户图与参考图都能被工具读取。若工具无法同时读取两者，不要悄悄退化成没有参考图的生成。

## 任务卡示例

以下是结构示例，替换为本次实际内容；不需要把它展示给用户。

```text
任务：制作一张可直接使用的竖版封面。上传母版9:16，默认1080×1920；以用户指定发布入口为准。
按居中的3:4作品格校验：1080×1920母版中，主页预览框为x=0..1080、y=240..1680。
完整文案和主要主体放进这个框的内部；标题避开框内左下角约10%高的播放量区域。上下延展区只安排可裁切背景。

图片1：用户提供的内容素材。
必须保留：[具体主体、身份、表情或物体特征；截图中哪些真实信息需要准确保留]。

图片2：参考海报 REF-[编号]，只从这张图建立视觉方向。
本次具体借用：[标题与主体比例、文字位置、图形穿插方式、配色、字重/疏密等]。
将参考里的视觉组织方法适配到图片1和以下中文文案，形成完整的新封面。
图片2的原文、原品牌和人物不能自动成为新封面的信息。

封面文字，逐字使用：
「[用户原文]」
允许断行、区分字重和字号；保持字序与文字内容。

构图安排：[结合用户图片与参考海报，描述具体位置、大小与层级]。
让主体与文案在缩略观看时仍可辨认；保留必要空间和画面边界。
不添加新人物、新产品、新观点、新卖点、无关图标、额外文字或水印。
保留用户主体，完成最终视觉与中文排字，输出一张完成版封面。
```

## 对应修正

- 错字：指出错误位置，给出准确原文，要求仅修正文字并保留已正确构图。
- 主体走样：重新提供原图，明确恢复哪些身份特征或真实界面信息。
- 参考联系不足：指出参考中本次应保留的两项具体视觉关系，修正对应部分，不增加新的风格参考。
- 信息太小或主体被遮住：调整主体与标题比例、断行和局部位置；保持文案原文和既定方向。

如果只有某段排字失败，可以使用当前可用的局部编辑/合成能力修复。没有可靠能力时说明具体限制，不用人工臆造界面或错误文字充当完成版。
