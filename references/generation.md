# 图生图任务卡

使用当前环境的实际图像工具执行。工具若有配套图像技能，遵守其输入和输出要求。工具不可用时说明缺少的能力，不私自寻找付费服务或伪造成品。

## 生成前

先查看用户图片和选定参考的完整图。缩略联系表用于选图，生成时传入选定参考文件本身。

读取[参考贴近与审美验收](reference-fidelity.md)。在内部明确用户图片中必须保留的主体、输入原文、最终上图英文、选定参考编号与文件；逐项写出主体位置与尺度、明暗留白、排字、色彩比例、图形作用和氛围如何对应。先建立贴近参考的核心构图，再适配文案与平台画幅。封面默认全英文：中文先忠实翻译，不把中文原文也印到图片上；用户指定最终英文时保持原样。

仅在用户要求制作或修改封面时执行本文件；只修订Skill规则时不生图。读取 [单张封面尺寸规则](platform-framing.md)。直接按3:4成品构图，默认1080×1440；提示词说明标题留边与左下播放量避让。平台界面示意图只用于判断框形，不属于创意素材。不制作9:16母版，不向上下扩展为其他比例。

将两张图通过工具支持的方式同时传入，并标明顺序与职责。必要时先把已选参考展示到图像上下文，确认用户图与参考图都能被工具读取。若工具无法同时读取两者，不要悄悄退化成没有参考图的生成。

## 任务卡示例

以下是结构示例，替换为本次实际内容；不需要把它展示给用户。

```text
任务：只制作一张可直接上传的竖版封面，3:4，默认1080×1440，最终交付单个JPG；以用户本次实际裁切框为准。
直接在这一张成品中组织全部内容，不做9:16母版或其他比例版本。
完整文案和主要主体在画面内留边，标题避开左下角约10%高的播放量区域。

图片1：用户提供的内容素材。
必须保留：[具体主体、身份、表情或物体特征；截图中哪些真实信息需要准确保留]。

图片2：参考海报 REF-[编号]，作为整体版式与审美约束。默认要求高贴近程度。
逐项对应：[主体位置/尺度/裁切；暗亮分布与留白；标题位置/行数/字号关系/字体气质；主辅色面积；线条或图形怎样连接主体；摄影处理/纸感/氛围]。
以参考的构图为底替换为图片1和以下英文文案，尽量保持整体视觉关系。适配画幅和文字长度，不重新发明通用封面排版。
图片2的原文、原品牌和人物不能自动成为新封面的信息。

封面文字，逐字使用：
「[本次最终英文；用户已给英文时用其原文，否则忠实翻译]」
允许断行、区分字重和字号；保持字序与文字内容。

构图安排：[结合用户图片与参考海报，描述具体位置、大小与层级]。
让主体与文案在缩略观看时仍可辨认；保留必要空间和画面边界。
不添加新人物、新产品、新观点、新卖点、无关图标、额外文字或水印。
保留用户主体，完成最终视觉与英文排字，输出一张完成版封面。封面中不出现中文及参考图原文。
```

## 对应修正

- 错字：指出错误位置，给出准确原文，要求仅修正文字并保留已正确构图。
- 主体走样：重新提供原图，明确恢复哪些身份特征或真实界面信息。
- 参考联系不足：并排找出具体偏离项，修正主体/留白、明暗、排字、色彩比例及图形作用等实际关系；不能只补几条线或同色装饰。不增加新的风格参考。
- 信息太小或主体被遮住：调整主体与标题比例、断行和局部位置；保持文案原文和既定方向。

如果只有某段排字失败，可以使用当前可用的局部编辑/合成能力修复。没有可靠能力时说明具体限制，不用人工臆造界面或错误文字充当完成版。

内部检查和必要修正不逐轮主动展示给用户。只有通过检查的最终成品才进入交付；不另外附裁切预览、缩略图或多种文件格式。
