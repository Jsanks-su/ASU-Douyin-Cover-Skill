# 上传母版与主页可见区

## 当前证据与适用范围

2026-10-27，用户提供了一张抖音个人主页截图，原图1280×2781。三列作品格单格约426×564像素，宽高比约0.755，与3:4接近。这是本账户当前截图的观察值，不是对所有抖音入口、版本和账号的统一规范断言。

另一个素材截图为1320×2868，但实际照片只在y=261..2607，共1320×2347，约9:16；上下纯黑区属于截图边缘。不能把手机截图的整张尺寸当成原素材画幅。

公开资料对普通主页、商城货架、直播和API投稿的尺寸描述并不相同。此次未获得可直接证明普通作品主页统一上传尺寸与裁切坐标的官方文本。因此，以下是依据用户实屏制定的工作默认值，最终以实际发布入口的裁切预览为准。不要引用商城或开发API的尺寸冒充普通主页规则，也不要承诺平台审核结果。

## 默认两层构图

| 用途 | 工作默认值 | 要求 |
| --- | --- | --- |
| 上传母版 | 1080×1920，9:16，RGB/sRGB，PNG或JPG | 实际导出后读取像素尺寸，不以提示词里的尺寸充数 |
| 主页裁切预览 | 母版中央1080×1440，3:4 | 只用于按截图模拟作品格，不自动当作上传母版 |
| 主页小图检查 | 同一裁切缩小至约320×427 | 主要标题可读，主体可辨，不靠放大才能理解 |

对1080×1920的母版，居中3:4框为`(0,240)–(1080,1680)`：上下各240像素不放必读文案、关键人脸或主要信息。

标题和主要主体还应在3:4框内留边。框内左下角存在播放量覆盖，默认预留底部约10%高度和左侧约65%宽度作为保守避让区；这也是设计避让值，不是平台固定UI像素。标题尽量在整张母版约79%高度之前结束，并以最终缩略图检查为准。

母版的上下延展沿用既定海报的颜色、纹理或背景。不要留下截屏黑边，也不要为了填满9:16把已经适合3:4的内容放大到超出可见区。可以先设计3:4核心，再整体缩放、定位并扩展背景到上传画布；生成器若改变文字位置，重新验收，不能默认生成成功即合格。

用户提供了发布器的实际裁切框、独立主页封面入口或另一种作品格时，优先测量当前截图并重算；不能坚持沿用默认居中框。真正上传、发布和修改线上作品需用户相应授权，制作封面不包含这些操作。

## 图像检查

1. 查看原图，识别照片画幅、纯黑边、状态栏和平台UI。内容图、风格图、平台示意图分别使用。
2. 查真实导出尺寸与比例；只允许必要的等比缩放、裁切、画布扩展等输出适配，不拉伸主体或字形来凑比例。
3. 从真实上传文件裁出主页预览，而不是另生成一张看起来相似的预览。
4. 在预览中逐字核对整句文案，检查边界与左下播放量覆盖区，再缩至手机作品格大小复查。
5. 最终只把母版标为“上传用”，把裁切图标为“主页预览”。两者必须属于同一个设计。

可用`scripts/check_framing.py`生成机械裁切与小图检查，需Pillow；也可用当前环境可用的等价图像工具。这个脚本只做导出校验，不代替图生图创作。

```text
python scripts/check_framing.py cover.png --out-dir framing-check
python scripts/check_framing.py cover.png --out-dir framing-check --title-box 0.08 0.46 0.75 0.79
```

`--title-box`是实际检查到的标题外接框，归一化到整张母版，不能凭空填写。脚本只能检查几何位置，不能证明文字正确、画面好看或一定通过审核。
